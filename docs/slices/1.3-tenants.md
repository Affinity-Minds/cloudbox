# Slice 1.3 — Tenant CRUD

## Goal

Super Admin and authorized staff can create, view, edit, and archive tenants. Tenants are the primary business unit; every device, subscription, and user belongs to exactly one tenant.

## Existing capabilities reused

- Tenant schema from foundation migration 0003
- Drizzle ORM for query building
- `requirePermission('tenant.*')` middleware
- Audit service for all mutations
- `@hono/zod-validator` for request/response validation
- Tailwind + shadcn/ui data table block for admin table
- TanStack React Table for sorting/filtering

## Data changes

**Schema (from foundation migration 0003):**
- `tenants(id 'ten_…' PK, public_code UNIQUE 'CBX-00481', display_name, legal_name, status CHECK('trial','provisioning','active','past_due','suspended','cancelled','archived'), primary_contact_email, support_contact_email, billing_contact_email, timezone, maintenance_window_json, renewal_warning_days INT, backup_policy_json, plan_code, notes, created_at, updated_at, archived_at)`

## Authorization

- Permission: `tenant.view`, `tenant.create`, `tenant.edit`, `tenant.archive`
- Query filters: no tenant data leaks between staff members (admin sees all; filters apply)
- Archive: only from non-archived states; refusal rules per spec

## Audit events

- `TENANT_CREATED` — tenant_id, creator_user_id, display_name, initial_status, timestamp
- `TENANT_EDITED` — tenant_id, field changes (before/after), editor_user_id, timestamp
- `TENANT_ARCHIVED` — tenant_id, reason, archived_by, archived_at

## Tests

**Happy path:**
- Create tenant with display name, legal name, contact emails
- Verify tenant_id generated, public_code UNIQUE assigned
- Edit tenant fields (except id, public_code)
- Archive tenant (transition to archived status)
- List tenants with filtering by status, name

**Permission boundaries:**
- Support user cannot create tenant (no tenant.create)
- Read Only user cannot edit tenant
- Verify 403 response for unauthorized edits

**Tenant isolation:**
- Tenant A admin cannot see Tenant B data
- Archive does not cascade device deletion (explicit protection)

## Demo path

```
1. Log in as Super Admin
2. Navigate to Tenants
3. Click "Create Tenant"
4. Fill form: display_name="Acme Corp", legal_name="Acme Corporation", emails
5. Submit
6. Verify tenant appears in list with status "trial"
7. Click tenant row to open detail drawer
8. Edit display_name to "Acme International"
9. Save
10. Verify audit log shows TENANT_EDITED event
11. Click archive (if UI supports it)
12. Verify status changes to "archived"
```
