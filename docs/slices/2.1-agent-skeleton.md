# Slice 2.1 — Windows Agent service skeleton

## Goal

A .NET Windows Service (`CloudBox.Agent`) runs with LocalSystem privileges, starts automatically after reboot, implements service recovery policy, provides structured logging, and supports deterministic repair/uninstall.

## Existing capabilities reused

- `.NET 8.0` worker service template (`dotnet new worker`)
- `Microsoft.Extensions.Hosting.WindowsServices` for service host lifecycle
- `Serilog` for structured logging to file + console
- Windows Service Control Manager (sc.exe, net start/stop)
- Named pipe IPC for local health endpoint (protected ACL)

## Data changes

None — this is Windows service infrastructure. Service state is in Windows Registry and service manager; CloudBox state is in D1.

## Authorization

- Service runs as SYSTEM; only SYSTEM and Administrators can stop/restart
- Health endpoint accessible only from localhost + service ACL
- Named pipe ACL: SYSTEM + Administrators read; others denied

## Audit events

- Service start logged to Event Log
- Service stop/restart logged
- Recovery triggers logged (if applicable)
- Crash/restart cycles monitored

## Tests

**Happy path (physical Windows test machine):**
- Install Agent via setup MSI
- Verify service exists in Services.msc
- Verify service starts automatically after install
- Restart Windows
- Verify service running after reboot
- Stop service via sc.exe
- Verify recovery policy (should restart after 5 seconds)
- Verify service restarts

**Failure paths:**
- Kill service process
- Verify recovery action applies
- Check Event Log for restart events
- Verify uninstall removes service entirely

## Demo path

```
Windows command prompt (as Administrator):

1. Run setup installer
2. sc query CloudBoxAgent  (verify status: RUNNING)
3. net stop CloudBoxAgent
4. net start CloudBoxAgent
5. Verify status = RUNNING
6. taskkill /im CloudBoxAgent.exe /f
7. Wait 5 seconds
8. sc query CloudBoxAgent  (should be RUNNING again)
9. Uninstall via Control Panel Add/Remove Programs
10. sc query CloudBoxAgent  (verify service gone)
11. Get-EventLog -LogName System -Source CloudBoxAgent (verify events logged)
```
